本版本集中修复请求处理和档案持久化问题，并补齐文档与自动发布流程。

- 复用 HTTP 会话；正确报告 HTTP 错误，修复集合参数与表单编码。
- 校验后台接口 JSON 和必填字段，避免错误请求继续执行。
- 修复档案清空；损坏文件加载和保存失败时保留原状态，避免重复档案 ID。
- 增加 Foundation 行为回归测试、版本校验和三模式自动构建。
- 完整更新记录见仓库 `CHANGELOG.md`。

附件：

| 安装包 | 环境 |
| --- | --- |
| `ProjectX-2.5.2-rootfull.deb` | Rootful，arm64，编译下限 iOS 13.0 |
| `ProjectX-2.5.2-rootless.deb` | Rootless，arm64，编译下限 iOS 15.0 |
| `ProjectX-2.5.2-roothide.deb` | RootHide，arm64，编译下限 iOS 15.0 |

`rootfull` 沿用工程拼写，含义为 Rootful。安装前确认越狱环境，并通过包管理器安装
`mobilesubstrate` 和适配当前环境的 `com.opa334.altlist`。不要同时安装多个模式。
下载后可用 `shasum -a 256 -c SHA256SUMS` 校验附件。

通过 CI 测试和编译不代表完成真机安装、启动和功能验证；Rootful / RootHide 的安装路径与脚本
尤其需要真机确认。现有“一键新机”和备份切换涉及数据及系统钥匙串清理，使用前备份重要数据。
