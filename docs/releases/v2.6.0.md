ProjectX 2.6.0 新增 GPT URL Scheme 兼容、设备参数编辑和档案管理功能。

- GPT 2.14-602 的 18 个命令可直接使用原有 `GPT://cmd/...` 链接。支持新机、档案切换、IDFA/IDFV 修改、应用版本覆盖和参数导入导出。脚本可读取 `/var/mobile/gptresult.txt` 获取执行状态。
- 参数导入导出使用 GPT 的 URL 和目录，文件采用 ProjectX JSON。5 个尚缺对应功能的命令及 GPT 原生 plist 格式互通已登记在 TODOLIST。
- 新增定位、时区、屏幕和应用版本等参数设置，以及选定应用的 SDK 兼容选项。档案支持按小时禁用、排序和 ZIP 导入导出。
